# בדק — אפליקציית בדיקת רכב לפני קנייה

אפליקציה עצמאית (קובץ HTML אחד) לניהול בדיקת רכב לצרכי קנייה ומכירה
לפי **הוראת נוהל 127** של משרד התחבורה (עדכון 1.10.2014).

## התקנה

### מקומית — בלי שרת
פתח את `index.html` בדפדפן. עובד גם מהמחשב וגם מהטלפון.
> שים לב: Service Worker (עבודה אופליין) פועל רק דרך `https://` או `localhost`,
> לא דרך `file://`. שאר הפונקציות עובדות בכל מקרה.

### GitHub Pages — מומלץ
1. צור מאגר חדש והעלה את כל התיקייה (index.html, manifest.json, sw.js, privacy_policy.html, icon-192.png, icon-512.png, .nojekyll).
2. Settings → Pages → Branch: main → Save.
3. פתח את הכתובת בטלפון → תפריט הדפדפן → "הוסף למסך הבית".

### APK
עטוף את אותה כתובת ב-PWABuilder או Bubblewrap ל-TWA.

## עדכון 1.5
- **גיבוי מלא עם צילומים** ושחזור בטוח: קודם נכתבים הצילומים, ורק אז מוחלפים הנתונים. קובץ זר נדחה.
  תזכורת גיבוי בדף הבית אחרי שבוע. קוד הנעילה ומפתח הבינה לא נכנסים לגיבוי.
- **קוד נעילה**: SHA-256 עם salt, הקלדה כפולה, 5 טעויות = המתנה של 30 שניות, נעילה אחרי שהייה ברקע
  (מיד / 1 / 5 / 15 דקות), טשטוש המסך ברקע. קוד מגרסה קודמת מוסב לבד.
- **מפתח הבינה מוצפן במכשיר** (AES-256-GCM, מפתח שאינו ניתן לייצוא).
- **"בטל" במקום "האם אתה בטוח"**: מחיקת בדיקה, הזמנה, צילום או אבחנה מתבצעת מיד, ו-5.5 שניות אפשר לבטל.
  אישורים פנימיים (לא של הדפדפן) רק לשחזור, לאיפוס רשימות ולמחיקת הכול.
- **מסך אבחון** (עוד ← אבחון): גרסה, אחסון, צילומים, שגיאות אחרונות, העתקת דוח בלי פרטי לקוחות.
- **מחיקת כל הנתונים** היא איפוס מלא, כולל הגדרות ומפתחות.

## עדכון 1.4

- **בינה**: מודלים עדכניים, דילוג על מודל שהוסר, ובדיקת חיבור שמושכת את רשימת המודלים של המפתח.
- תאריך מקומי (לא זז יום אחורה בלילה), גיבוי כולל את רשימות הליקויים שערכת, `privacy_policy.html` כקובץ נפרד.

**בכל עדכון:** מעלים את `VERSION` ב-`sw.js` ואת `APP_VER` ב-`index.html`.

## מה נמצא בפנים
- **446 אבחנות** מנספח 5 בנוסח המחייב, ממופות ל-25 סעיפי נספח 1 ול-21 סעיפי נספח 2.
- **6 רשימות שלדה** (שלדת מרכב / שלדה נפרדת × גבוהה / נמוכה / שולית) שנבחרות אוטומטית.
- שליפת נתוני רכב מ-data.gov.il + זיהוי גלגול מד-אוץ, שינוי מבנה, שינוי צבע וריקולים.
- מנוע התאמת אבחנות: חוקים (חינם, אופליין) או API (Claude / Gemini / OpenAI / מודל מקומי).
- צילומים ב-IndexedDB עם דחיסה אוטומטית, נתונים ב-localStorage.
- הפקת דוח: טופס אחיד + נספח ממצאים וצילומים נפרד.
- 5 שפות, 5 ערכות צבע, מצב יום/לילה, גיבוי JSON/CSV.

## דבר אחד שצריך לבדוק פעם אחת

אם הפנייה הישירה מהדפדפן ל-data.gov.il נחסמת, הזן שם כתובת proxy.
