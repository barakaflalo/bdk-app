# בדק — אפליקציית בדיקת רכב לפני קנייה

אפליקציה עצמאית (קובץ HTML אחד) לניהול בדיקת רכב לצרכי קנייה ומכירה
לפי **הוראת נוהל 127** של משרד התחבורה (עדכון 1.10.2014).

## התקנה

### מקומית — בלי שרת
פתח את `index.html` בדפדפן. עובד גם מהמחשב וגם מהטלפון.
> שים לב: Service Worker (עבודה אופליין) פועל רק דרך `https://` או `localhost`,
> לא דרך `file://`. שאר הפונקציות עובדות בכל מקרה.

### GitHub Pages — מומלץ
1. צור מאגר חדש והעלה את כל התיקייה (index.html, manifest.json, sw.js, icons/).
2. Settings → Pages → Branch: main → Save.
3. פתח את הכתובת בטלפון → תפריט הדפדפן → "הוסף למסך הבית".

### APK
עטוף את אותה כתובת ב-PWABuilder או Bubblewrap ל-TWA.

## מה נמצא בפנים
- **446 אבחנות** מנספח 5 בנוסח המחייב, ממופות ל-25 סעיפי נספח 1 ול-21 סעיפי נספח 2.
- **6 רשימות שלדה** (שלדת מרכב / שלדה נפרדת × גבוהה / נמוכה / שולית) שנבחרות אוטומטית.
- שליפת נתוני רכב מ-data.gov.il + זיהוי גלגול מד-אוץ, שינוי מבנה, שינוי צבע וריקולים.
- מנוע התאמת אבחנות: חוקים (חינם, אופליין) או API (Claude / Gemini / OpenAI / מודל מקומי).
- צילומים ב-IndexedDB עם דחיסה אוטומטית, נתונים ב-localStorage.
- הפקת דוח: טופס אחיד + נספח ממצאים וצילומים נפרד.
- 5 שפות, 5 ערכות צבע, מצב יום/לילה, גיבוי JSON/CSV.

## אחסון
| סוג | איפה | למה |
|---|---|---|
| בדיקות, הזמנות, הגדרות | localStorage | קטן ומהיר |
| צילומים | IndexedDB | localStorage מוגבל ל-5–10MB |

הכול נשאר על המכשיר. אין שרת ואין חשבון.

## דבר אחד שצריך לבדוק פעם אחת
הגדרות → משרד התחבורה → **בדיקת חיבור**.
אם הפנייה הישירה מהדפדפן ל-data.gov.il נחסמת, הזן שם כתובת proxy.
בלי זה האפליקציה עובדת רגיל — פשוט במילוי ידני.

## הערה משפטית
הטופס האחיד מחייב לוגו ומספר רישיון מפעל של מכון מורשה, ואסור להוסיף או לגרוע ממנו פרט
(סעיף ה.17). כל עוד שדה "מס' רישיון מפעל" בהגדרות ריק, הדוח מופק מסומן **"טיוטת בדיקה"**.
